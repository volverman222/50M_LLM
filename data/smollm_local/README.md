# Datos requeridos

Coloca en este directorio los mismos datos locales que utiliza el notebook de
referencia:

- `train.txt`: texto UTF-8 para entrenamiento. El entrenamiento consume como
  máximo 1.000.000 tokens SentencePiece.
- `validation.txt`: texto UTF-8 para calcular `test_loss`.

Estos archivos no estaban presentes en el proyecto al crear este paquete, por
lo que no se han inventado ni descargado datos alternativos.
